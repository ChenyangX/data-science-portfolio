# Data Science Portfolio Reflection

Creating this data science portfolio helped me connect the technical skills developed in CISC7204 with the broader process of communicating analytical results. Rather than presenting notebooks as isolated coursework, I organized my work into three projects: a semester project on Macao tourism, Assignment 01 on data analysis with Python, and Assignment 02 on data visualization.

The Macao tourism project was particularly valuable because it required me to think about the relationship between data preparation, analytical questions, and visual storytelling. Working with multiple datasets highlighted the importance of checking consistency, understanding limitations, and selecting charts that support meaningful interpretations.

The two assignments document my progress with Python-based analysis and visualization techniques. They also show how different plotting approaches can reveal trends, comparisons, and distributions while introducing the risk of misleading presentation choices. Preparing the portfolio encouraged me to improve documentation, organize files clearly, and make my work easier for others to reproduce.

One challenge was balancing the completeness of original notebooks with the readability of a public project. I addressed this through separate repositories and explanatory README files. In future projects, I hope to strengthen reproducibility, add clearer methodological validation, and build more interactive visualizations.

Overall, this portfolio represents both my current learning outcomes and a foundation for future data science work.
